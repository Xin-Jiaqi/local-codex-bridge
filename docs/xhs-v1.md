## 二、正文 caption（≤1000 字，发布用，直接粘贴）

ChatGPT 只能聊天？也能当你的「本地操作员」。

Local Codex Bridge 是一个开源小项目：给 ChatGPT 开一个 HTTP 接口，接上本机
Codex CLI 的 app-server，让对话里的指令真正落到你的工作区：读写文件、跑
shell、连续多轮完成任务。不用再复制粘贴命令来回搬运。

架构很简单：ChatGPT → GPT Actions（HTTPS）→ ngrok 隧道 → 本机 Bridge →
Codex app-server → 模型（DeepSeek）。一共 7 个 action：start / continue /
observe / steer / interrupt / list / read，长任务靠 observe 轮询，想插话用
steer 排队。

安全上做了克制设计：默认 workspace-write 沙箱，工作区外自动拒绝；需要
Bridge 自己 git commit/push 时，可以切到 v1.1.0 的 bridge-workspace 最小授权
profile：只放开项目 .git 写入和 GitHub 域名白名单，不依赖本机代理；
danger-full-access 仅显式选择，风险自担。启动由 launchd 管理，登录自启，
状态随时可查。

适合谁：想让 ChatGPT 帮你写代码、跑测试、整理仓库的开发者。注意它是个人单机
工具，没有审批流和多用户审计。

开源在 GitHub（BSD-3-Clause），链接放评论区。详细文档和已知限制见 README，
欢迎 issue。
